## Решения

1. Собственный unsafe запрещён, кроме изолированной FFI-границы с безопасным
   API и SAFETY-обоснованиями. Обычные Rust roots — forbid, FFI-крейт — deny
   с локальным исключением. Кодовый файл ≤700 строк, каталог ≤7 элементов;
   документация не подпадает под лимит строк.
2. Первичный исследованный стек: iroh 1.3.0, Mainline-адаптер 0.6.1,
   libp2p 0.57.1 + libp2p-stream 0.5.0-alpha, yggdrasil-go v0.5.14,
   ktav 0.8.0. Это карта контрактов, не уже добавленные зависимости:
   текущий каркас содержит только локальные path-зависимости. Не повышать
   версии без отдельной просьбы.
3. Нельзя объявлять signaling-only доказанным по счётчикам зашифрованных
   пакетов, `PathSelection::none()` или отключению транспорта после direct.
   P03 требует decoded STREAM/служебных кадров с привязкой к фактическому
   egress path и калибровкой на заведомо разрешённом STREAM.
4. Mainline не пишется автоматически с нуля: исследован отдельный адаптер.
   Его default relay_only отбрасывает наши CustomAddr; нужен явный фильтр.
   DNS-часть pkarr ≤1000 байт, заголовок 104, signed packet ≤1104.
   Равная sequence с тем же содержимым — идемпотентное чтение, не обязательный
   отказ; повтор не должен продлевать допустимый возраст подписанной записи.
5. Commit/push явно разрешены пользователем через AskUserQuestion для этого
   проекта. Публикация crates/releases не разрешена. После каждого push
   немедленно ставить фоновый `gh run watch` или `gh pr checks --watch -i 60`.
   Не запускать локальные cargo check/build/test, Go build/test или unittest.
