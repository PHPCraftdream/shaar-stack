### Prepared relay API and mandatory #118 obligations

Additive exports:

```text
client::new_with_operation_factory(local_peer_id, factory)
client::OperationFactory
client::OperationDescriptor
client::OperationKind
client::OperationCapability
client::OperationOwner
OperationCapability::owned(descriptor, admit, released)
```

Existing client::new stays compatible. Factory must consume exact trusted, precharged staged intent at the transport CALL, not look up a successor when queued work runs. `admit(&descriptor, Option<ConnectionId>)` reads the caller's single authoritative ledger, including generation, role/origin, peer, pinned endpoint, kind/destination, deadline and authenticated control. Descriptor alone grants no authority; None control is not blanket peer-wide permission. Active reservation lifetime is independent of a completed transient dial attempt.

**Critical release trap established by both advisers and parent source inspection:** OperationOwner itself retains the same Arc. cancel() does not release that reference. SDK must withdraw ledger eligibility, unlock, extract/cancel/drop owner, and only then await release of all capability/future/event/placeholder references. Do not keep owner until its own released callback; avoid strong ledger → owner → callback → ledger cycles, use weak captures or explicit break. Last-drop callbacks and wakes must be outside ledger guards. Gate has no deadline timer; owner expiry handling must wake/cancel/drop explicitly.

Native guards alone cannot revoke existing connected reuse/renewal. Stop/reset/disconnect initiates bounded teardown but can race independently polled handler work and late responses. A poll admitted before revocation and serialized bytes may finish; that does not allow fresh activation, another protocol poll, acceptance or publication. Whole-carrier completion of run remains the joined-resource barrier, not release acknowledgment or ConnectionClosed alone. Keep existing 10-second teardown fallback and independent reservation references through unrelated query cancellation.
