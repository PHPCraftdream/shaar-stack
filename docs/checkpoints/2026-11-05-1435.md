- Адаптер живёт во вложенном крейте `shaar-ygg-core` со своим lock (вариант C): продуктовый граф SDK не тронут до P10.

- Датаграммы остаются ненадёжными по контракту; нагрузочные тесты умеренные и не доказывают доставку без потерь.
