## Decisions

- Explicit native admission после TLS/source/ALPN использует original caller socket address, один прежний 10 s budget и private unpublished Session guard. Handshake completion не означает path validation или CID readiness; event-driven CID hint не является reservation.
- Retention живёт на существующем per-PathId PathState, не на заменяемом при migration PathData. Admission и automatic close-if-unretained используют один Noq connection mutex; getter-then-close был бы TOCTOU. Никаких новых maps/queues/tasks/locks/config для pin не добавлено.
- libp2p-kad prepared boundary доказывает 32 referral-map peers, 4 unique addresses/peer по 256 encoded bytes и 32 lifetime states на один closest iterator, но НЕ 32 global contacts для bootstrap/disjoint operations. Owner #67 ещё обязан ограничить операции, роли, TTL, cleanup и deadlines.
- DNS #85 ограничивает только libp2p-owned expansion: 4 numeric alternatives, 16 accepted TXT, 32 pending, 256 encoded bytes, 1024 whole decoded TXT bytes и 16 error entries; arbitrary error payload bytes/Hickory decoder/cache/task memory пока не ограничены этим доказательством.
- Зелёный diagnostic rerun не считается исправлением timeout. Сначала phase evidence, затем owning-layer fix и regression. Нельзя увеличивать deadlines, менять custom-first ordering, ослаблять assertions/NativeOnly или добавлять blind retries.
