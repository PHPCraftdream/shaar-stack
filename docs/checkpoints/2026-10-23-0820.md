## Decisions

- Сохраняем один QUIC connection и проверенный pre-packetization STREAM/DATAGRAM gate, а не новую signalling cryptography или post-encryption payload filtering. Current classifier запрещает ВЕСЬ synthetic fabric/custom/relay; это НЕ selected Ygg transport-instance authorization.
- Production dependencies готовятся отдельным checksum-pinned source-data шагом до Cargo, а не скачиваются/патчатся внутри `build.rs`. Нет нового публичного fork или package publication; upstream source trees — generated dependency artifacts, не способ скрывать собственный maintained code от 700/7.
- Resource admission разделена по владельцам: pending Initial count/byte buffers, raw async datagram queue, allocated connection metadata до Drained, затем SDK handshake/session/stream/task admission. Один semaphore или application flow control не доказывает все эти границы.
- Raw UDP overload admission не классифицирует STREAM ciphertext: целые datagrams могут теряться как обычный UDP congestion, control-event delivery остаётся отдельной, а signaling-only enforcement всё ещё выполняется до packet encryption.
- SDK API должен не раскрывать seed/raw iroh builder/uncontrolled endpoint clones. Identity networking bridge — только crate-private clone safe SecretKey; EndpointHooks не должны удерживать Endpoint или strong Connection, создавая cycle/отменяя close-on-drop.
