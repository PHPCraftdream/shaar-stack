- Сохраняем один QUIC connection и исследуем минимальный pre-packetization backend gate, а не придумываем новый криптографический signalling protocol. Цена — поддержка проверяемых Noq/iroh patches; production adoption ещё нет.
- Payload permission/readiness отделены от control scheduling; denied payload остаётся в очередях, Available forbidden path не затеняет разрешённый Backup. Pure/nonblocking function-pointer policy в spike доверенная, а синтетическая IP-классификация тестов не является production transport authentication.
- PTO probe не равен объявлению STREAM lost: исправлен неверный тестовый механизм, а не recovery backend ради зелёного CI. Security assertions и exact-byte/FIN proof сохранены.
- Новый minimum-one DATAGRAM budget меняет только accounting empty records, не wire format и не charge nonempty payload. Zero budgets теперь не допускают empty records; это явная semantic boundary, ещё ожидающая CI-подтверждения, не готовая production гарантия.
