## Decisions
- chose an own UPnP client over `igd-next` because the library would add `igd-next`, `attohttpc`, `xml-rs`, `xmltree` and `h2` to the shipped graph, each needing notices and two re-rendered release manifests (the hash of the rendered notice file is inside them); the owner's later blanket permission for libraries does not change that cost, so the change was reported instead.
- chose to leave the `alloc` feature of `argon2` off because it enables `password-hash` and `phc` and would break `--locked` in CI; the code supplies the Argon2 memory blocks (`hash_password_into_with_memory`).
- chose `RouterMapping` off in the library and on in `RoleOptions::products()` (the binaries) with `SHAAR_ROUTER_MAPPING=off` as the switch, and a keeper that finds the home router in its own task so that the cancel-safe role phases do not wait.
- chose carrying the password arguments inside the `key` commands and installing the sources once for `run`, `connect` and `address`, instead of a global in every call site of the key loader.
- chose to design DIRECT-T before coding it: the fixture runs product children unprivileged, snapshots the router table as immutable and has a closed environment allowlist, so the responder must be a controller-owned privileged process and the DNAT must live in a table of its own.
