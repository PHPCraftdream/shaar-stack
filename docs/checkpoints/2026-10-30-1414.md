## Decisions

- Обычный CI автоматически выбирает owning-module cases по cumulative feature diff; full только по standalone `[ci:full]` текущего candidate commit либо manual Actions `scope: full`. Ни одного hidden full fallback; targeted pass не равен full-sprint acceptance.
- Discovery provenance привязана к immutable full AttemptKey/source generation, absolute deadline и lifetime budgets; query finish/waiter drop не заменяют actual I/O terminal ownership и release permits.
- Handoff сохраняет Infrastructure role; per-operation Authority::Discovery проверяет exact live witness/endpoint/control. Pending reservation не получает новый discovery deadline; actual accepted lease затем владеет своим expiry.
- SDK caller принимает validated in-memory DiscoveryConfig, использует ту же Identity и retained coordinator. Server/Client ktav schemas/direct-only defaults не менялись, implicit bootstrap/reservation не добавлены.
