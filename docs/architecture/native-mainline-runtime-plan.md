## #246 — specification and tests first

Owned deterministic tests use controlled clocks, numeric loopback fixtures and actual UDP; exercise production-path seams. No public traffic, DNS/default bootstrap, source execution or fake counter as security oracle.

1. **Record/trust:** existing codec tests cover checked signed decode and exact expected-key match. Reuse existing checked-decode/profile tests; next tests exercise available public upstream `EndpointInfo`/encoder delegation and proposed timestamp helper. `TxtAttrs` is crate-private and not directly callable. Negative inputs cause no cache admission or actual dial. Independent reference bytes only with provenance/digest. Preserve 1000/1104 limits; investigate parser allocation/depth and truncated datagrams.
2. **Ordering/cache:** completed real DHT query supplies verified observations/provenance. Seq 10 then 11 and reverse; lower cannot poison watermark, equal identical, equal conflict, greater clears conflict. Mutation oracle catches N latest-only bug. Fresh identical result from a new network query may renew; duplicate response, local PUT, cache replay, active PUT/cache-only or in-query duplicate cannot. Test exactly 300s inclusive boundary, zero-TTL immediate result, future tolerance 30s, cache receipt 30s, checked overflow and raw negative sequence before cast. Wall rollback is terminal. Watermark for 64 keys persists; no expiry eviction. Cancellation/late completion cannot cache or dial.
3. **Publisher:** empty, withheld, invalid replacement and explicit revoke revoke current generation before validation; never publish observed/bound socket snapshot. Fresh timestamp each 60s: `max(wall,last+1)`, checked `i64`, <=wall+30s; C helper only, upstream signing/preimage. Async acknowledgement only after send cleanup/generation transition. Cancel before ack revokes; after ack publication persists until withdrawal/close. On backward wall-clock detection owner enters terminal clock-fault state, clears usable cache and stops work while retaining watermarks; catch-up never resumes it. This is not rolling back publisher/resolver state. Local signing by upstream is fine; no custom signing/preimage implementation. No claim of remote DHT erasure.
4. **Admission/retention:** absolute 10s caller deadline covers queue/bootstrap/retries; max 3 rounds/PUT attempts, full jitter <=100ms/200ms. Deadline before enqueue; charge held through cleanup. Cancellation carries operation IDs through shared-target waiters; remove cancelled waiters, retain shared query budget; outbox generation tagging; cancellation cannot reset deadline. Ten-second held cleanup consumes slot. Boundary tests at each limit and controlled barriers, no sleeps.
5. **Bootstrap/shutdown:** numeric endpoints only, validated before bind; bypass sync resolver/defaults. Distinguish fixture-owned loopback bind/destination containment from production wildcard bind/referrals; hostile referral cannot escape fixture guard. Observe actual UDP destination/receipt. Out-of-band stop works around flush/receive; retain actor join handle, no self-cycle. Five-second close is reporting boundary: if not joined, report failure and retain owner/handle/charges; consuming close must not drop it. Success requires join, socket destruction, successful fixture socket rebind; cloned handles inert.
6. **Dial/client-only:** bad records assert actual dial attempt/destination and cache admission are zero. Positive path uses exact expected peer key for validated record and existing TLS-pinned `Endpoint::connect`. Test adaptive client and responder guards separately; cannot re-enable after 15 minutes; no server scope. This is client-only, not responder behavior.

### Proposed hard caps and enforcement

| Resource | Exact cap | Enforcement / unresolved feasibility |
|---|---:|---|
| Operations / queued | 8 / 16 | Charge before enqueue; per-operation deadline starts before enqueue. |
| Payload | <=1104 bytes | Reject before allocation/queue; DNS payload 1000, full packet 1104. |
| Candidate / visited | 256 each, owner aggregate | N iterative closest/responders/visited plus bounded routing, query cache, votes and transaction IDs. Not per-operation multiplication. Prove aggregate ownership; disable cache profile or choose within aggregate if infeasible, never silently add 1000 cached entries. |
| RPC | 128 total, 16/op | Aggregate admission; one maintenance op. Include populate/refresh/ping and send-failure rollback. |
| Outbox | 128 datagrams, <=2048 bytes each | Pre-enqueue; `send_datagram` escape route also charged. Generation tagging and cleanup. |
| Results | 8 channels; 32 entries and 65,536 bytes/op | N `src/dht.rs:430` creates an unbounded result channel; `src/actor.rs:413-435` retains waiter vectors and `src/core/iterative_query.rs:20-27,177-184` retains responses. Bound each before growth, terminate on overflow, and never block the actor awaiting channel capacity. |
| Protected keys / winner | 64 keys; 1104-byte full winner | Preserve watermark/conflicts; no eviction. |
| Addresses / time | 4 addresses; DNS <=1000 bytes/full packet <=1104 bytes; TTL is not freshness authority | Validate limits before storage/dial. |

Ops queue payloads are fixed controls and bounded. No successful commit at or after 10s; cleanup is separate, with no attempt after cancellation. At most three rounds/attempts total, not three retries after an initial attempt; coalesce missed ticks and wait for the next 60s tick on exhaustion. Normal-clock local publisher behind previous remote sequence fails until catch-up; terminal rollback never auto-resumes. No lock across await; no detached tasks. Acceptance caps are PROPOSED, pending feasibility and parent review.
